# Основа для интернет-магазина
### Описание проекта: для этой основы возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.
### Реализованы задачи проекта:
  - Созданы классы Product и Category
  - Для классов Product и Category описаны все необходимые атрибуты
  - Для всех классов написаны тесты для проверки работоспособности кода
  - Реализована подгрузка данных по категориями и товарам из файла JSON
  - Cоздан класс ProductIterator, который принимает на вход объект класса категории и производит итерацию
    по товарам, которые хранятся в данной категории
  - Созданы классы LawnGrass и Smartphone, которые наследуются от родительского класса Product. 
    Наличие этих классов позволяет разделить товары по категориям и производить
    операции над товарами конкретной категории.

## Тестирование программы ##
В программе реализованы функции тестирования для модулей *utils.py, category.py, product.py*
Все тесты расположены в папке *tests*, с названиями *tests_имя тестируемого модуля*

Запуск тестов осуществляется через терминал.

Результаты выполнения тестирования можно посмотреть, выполнив команду в терминале:
```
pytest --cov
```

Готовый отчет с результатами тестов хранится в репозитории в папке:

*htmlcov / index.html*

Сформировать новый отчет командой в терминале:
```
pytest --cov=src --cov-report=html
